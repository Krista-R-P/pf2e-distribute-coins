# PF2e Distribute Coins

A module for Foundry VTT that makes splitting party loot easy in Pathfinder 2e games.

## Overview
PF2e Distribute Coins automates the process of dividing coins from a party actor to all player characters. It uses the PF2e system's inventory API and is designed for quick setup and reliable operation.

## Features
- One-click coin distribution from a party actor to all player characters
- Automatically excludes all non default characters.
- Uses the official PF2e inventory API for safe transactions
- Notifies players via chat message with a summary of the split
- Handles leftover coins and returns them to the party actor

## Installation
1. Add this module with this manifestation link: https://github.com/Krista-R-P/pf2e-distribute-coins/releases/latest/download/module.json.
2. Enable the module in your Foundry VTT game under **Manage Modules**.

## Usage
### As a Player
- Open your party actor's sheet.
- Click the **Distribute Coins** button in the currency section.
- The module will split all coins among player characters and notify everyone in chat.

### As a Gm
Pathfinder 2e already provides a way to distribute coins so the button is diabled for GMs.

## Compatibility
- Requires Foundry VTT and the PF2e system
- Designed for Pathfinder 2e games
